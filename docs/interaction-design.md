# 交互设计

## 1. 两个入口，不造工作台

- **顶部灵动岛为日常主入口**：原创AppKit无边框non-activating panel＋SwiftUI，compact胶囊显示Pi标识/运行/待输入数，hover或点击后展开真实会话卡片；事件到达不自动展开或抢焦点。刘海屏以safeArea/摄像头空隙避让，普通屏/外接屏用顶部胶囊fallback，不扫描其他App窗口或要求新系统权限。菜单栏作为始终可用的备用入口。
- **独立管理窗口**：左侧“会话 / 子任务 / 计划 / Token / 重要事项 / 设置”；中间当前对象列表；右侧详情与有来源的状态、管理动作。窗口关闭不退出Pi、不停止工作。
- 设置只包含本App的显示、通知表现、明确接入和现有管理页链接。不提供模型/权限一键降级、全局工具开关或第二套业务策略。

[打开静态合成预览](design/pi-desk-v0.1.html)。预览仅HTML/CSS文档，没有脚本、网络、真实账号或真实管理动作；按钮不可执行。它不是后续技术栈选择，实际App仍为SwiftUI/AppKit。

## 2. 默认视图

默认是“会话”的“在线”筛选；断连卡仅隐藏于默认主列表，仍可在“全部/断连”查看，不停止或删除Pi。搜索、状态、隐藏都作用于`visibleSessions`，主列表与可见计数一致；过滤外对象不继续显示可误操作的详情。长名卡片两行截断，详情完整；子任务操作在主详情折叠，避免堆满空表单。重要事项作为独立入口，不用红色待办把正常空闲和回合结束全部变成待人工处理。

每张卡片以会话/项目名为第一层，中文状态＋图标/色标为第二层，模型/分支、当前工具和准确子任务投影为次要信息。优先真实待输入，再异常、运行和安静的回合结束；“回合已结束”不叫目标完成。长名截断但可读完整辅助标签。source/epoch/runId/raw协议与coverage原因移入可展开诊断；未知/部分覆盖/断联仍以中文出现在正常层，不抹掉真实性。默认不展示大空白输入框，追加/纠偏在准确卡片旁按需展开，消息始终绑定会话epoch。

选中对象的控制条仅含有真实接线的动作：

| 动作 | 交互含义 | 回执与边界 |
|---|---|---|
| 打开原会话 | 只跳转准确终端/Herdr面板 | 找不到则失败，不假装打开别的窗口成功 |
| 追加要求 | 默认原生follow-up，保留当前工作 | 无原生收据只显示已请求，证实后才标排队，非已完成 |
| 纠偏 | 明确steer，在原生安全边界进入 | 不先杀当前工具再重启 |
| 中止当前回合 | 只请求当前会话abort | 标注不保证停止后续队列/子任务/外部副作用 |
| 停止子任务 | 对准确owner/runId请求stop | 从“请求停止”到owner确认终态，不提前变绿 |
| 恢复子任务 | 保留原任务，由owner验证恢复资格 | 不支持时不退回“新开一个同任务” |
| 暂停计划 | 停未来触发，保留正在执行的工作 | 与停止当前运行分开按钮/说明 |
| 已读/静音 | 改通知表现 | 不代答问题、不改变执行 |

普通动作不追加通用“是否继续”弹框。已有owner硬规则或真实必要决策沿原流程，UI不新造审批；本地明确目标的提交是用户意图，不是为每次自动执行取确认。

## 3. 子任务与计划

子任务按父会话分组，显示正在运行/回传中/已结束/未知。独立注册的同一孩子可以被链接，但不复制成两份统计。前台/后台来源不足时显示“关系待核”，不猜父亲。

计划按owner命名空间分组，不按同名合并。缺少在线管理接口时显示“打开原管理入口”，不提供伪按钮或直接写文件。计划历史只用原owner已有运行元数据，不变成会话历史浏览器。

## 4. Token 页面

主页面为“Pi总用量”，默认今日，提供近7天/本月/自定义起止日期；跨所有已记录会话。主卡优先“交互Token（input+output）”，同时显式列缓存读取/写入和“记录总处理量（四桶下界）”，不把缓存复用量当新增输入或账单。趋势、数据表、模型分布共用交互/缓存/全部选择，默认交互，避免缓存量淹没主活动；三者总和口径一致。明确展示UTC/本地时区、实际已有记录覆盖起点和刷新状态；会话维度仅次级下钻。

“上下文占用”单独展示，不能叫已消耗Token；缺值显示“未知/尚未结算”。时间图表来自持久实时final和2026-10-26授权的一次历史usage元数据补采；实时记录/一次性历史补采/去重合计可切换，来源卡片对齐当前日期与模型，覆盖起点随来源变化，历史收据展示冻结覆盖日期/缺链/未知模型/缺字段等原因。实时与历史重叠沿用原来源、fork复制只计原消费；App启动和刷新不重扫旧日志；未采集日期用空缺/文字而非零柱，部分字段显示已知下界；未来范围无数据不伪称已采集。自定义结束日期早于开始日期时不发查询、不偷偷改成开始当天；保留旧结果和旧范围标签，明确提示修正日期。费用无依据则隐藏金额。

## 5. 重要事项与治理

实际input-required优先；其次是任务级失败和需关注异常，再是结果未读。自动重试中显示原因与进度，但不要求点继续。每项写明来源和时间；Gate/CI摘要区分判定head、实际merge及post-CI，不用一个“成功”图标包办。

没有接入的来源保持“未配置/不可用”，不会影响其他会话。没有新需求，不新增AI诊断模型。既有模型建议以“建议”显示，不能覆盖规则。

设置页提供“开启系统通知”：只有用户显式点击才调用标准系统通知授权；用户是否允许仍由系统提示决定，App不自动点击或启动申请。拒绝/申请失败/发送失败均解释原Pi通知与自动化不受影响；重复点击只保留一个在途申请。

## 6. 空、错与断联

- 空列表：“尚无已接入Pi会话”，提供原扩展加载说明；不扫描历史以填满界面。
- 断联：保留最后更新时间并置stale；不改成任务失败，不重发管理请求。
- 新epoch：清掉旧可操作状态，重新获取capabilities；不保留可误点的旧运行对象。
- 未确认操作：展示unknown和原操作引用，给查询入口；没有证据不启用“自动重试”。
- Token partial：显示缺失范围/owner未覆盖数量，不写0。

## 7. 顶部展开与收起

compact/expanded为真正窗口状态，不是菜单弹窗；卡片、滚动及轻量输入只在展开态出现。离开延迟收起，pin或正在键盘编辑时不自动收起；Escape先退出编辑，再在非pin时收起，显式收起按钮可取消pin。仅用户点击输入才使panel获得键盘焦点；普通事件不弹主窗。所有展开/收起动效遵循Reduce Motion，主窗和顶部共用准确状态映射与管理路径。

参考CodeIsland的黑色顶部区域、卡片层级和节奏，但不复制其源码/角色/素材，不增加消息正文、工具参数、历史或LLM摘要来补视觉内容。原生预览使用显式合成fixture并禁用真实管理递送，不能把预览截图当实际owner闭环。

## 8. 原生实现验收

支持键盘导航、VoiceOver、动态文字、非颜色状态、减少动态效果、外接屏和无刘海屏；全屏/锁屏/显示器变化不阻塞主任务。不抢焦点，不自动打开控制面板盖住正在操作的应用。原生候选已有窗口/顶栏和AX控件，可用CUA在后台显示两个隔离SDK会话并提交native消息，界面保留requested而非假queued；空态、断联和提示也有实现。完整VoiceOver、系统通知交付、Herdr实机跳转与长期组合仍未完成。静态预览只用于设计参照，不是运行证据。
