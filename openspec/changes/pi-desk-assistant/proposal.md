# Why

把提醒、接入诊断、未发送草稿、快捷操作和多会话组织形成可用闭环；用户另批准可配置Pi注册模型的AI辅助基座，默认codex-local-8319/gpt-6.1-sol、medium。

# What Changes

- 通知点击绑定原会话准确runtime；集中接入健康、退出草稿防丢和Cmd-K动作面板。
- 顶部速览/仅菜单栏/固定展开及屏幕选择；手动工作组与AI建议分组。
- 通过兼容在线Pi的公开ModelRegistry提供按需分析，不另建带工具的Agent、不改业务模型或会话。AI不可用不影响基础能力。
- 经用户选择，按需读取所选已接入会话当前分支的有界近期用户/助手文本；不读思考、工具原文、凭据文件或历史目录。展示上下文预览和移除入口，检测疑似敏感值时阻断AI发送；不声称自动识别所有敏感信息。
- 模型和思考档可修改，结果有来源与时间、可取消、不可静默换模或重试，用量独立于业务会话记录。

# Impact

原生App、bridge可选AI协议与合成测试；旧bridge缺新能力明确降级，不强reload。AI只生成建议，不获得管理或执行权限。基础观察/控制仍无默认模型调用。
